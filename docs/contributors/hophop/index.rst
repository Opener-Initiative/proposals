hophop
======

The hophop project is developed as part of the Ariel OS organization,
available [on GitHub](https://github.com/ariel-os/hophop),
and provided as a contribution to the Opener project.
It is written in Rust, and thus not directly applicable for code transfer,
but nonetheless exchanging tools, documentation,
and maybe integrating through C APIs at some time.
