Conformance Test
################

The Conformance Test Specification – Part 2: Radio Protocols (`ETSI TS 104 047-2 V1.1.1 (2025-10) <https://www.etsi.org/deliver/etsi_ts/104000_104099/10404702/01.01.01_60/ts_10404702v010101p.pdf>`_) discribes in chapter A3.1 the following test system configurations:

* **CF01**: Test System as an observer
* **CF02**: Test System in PT mode
* **CF03**: Test System in FT mode
* **CF04**: Test System as FT + PT
* **CF05**: Test System as FT + FT
* **CF06**: Test System as FT + PT + FT-PT

.. note::
   The following table is based on `ETSI TS 104 047-2 V1.1.1 (2025-10)
   <https://www.etsi.org/deliver/etsi_ts/104000_104099/10404702/01.01.01_60/ts_10404702v010101p.pdf>`_. Test cases/Test Purpose (TP ID) of chapter 7 and mapping to the test sequences for chapter 8.

   Total test cases: **56** (MAC: 44, DLC: 8, CVG: 4)
