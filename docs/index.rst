Opener Proposals
================

.. important::
   This repository is in a draft state and is currently a space for collecting input
   documents for the *Opener* stack implementation. It is inappropriate to use it as
   reference material or to cite it other than as "work in progress."

This repository is where ideas and proposals for the
`Opener Initiative <https://github.com/opener-initiative>`_'s **DECT-2020 NR (DECT NR+)**
protocol stack implementation are put forward, discussed, and refined. The implementation
and its documentation are maintained separately.
