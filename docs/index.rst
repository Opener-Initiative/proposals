Opener Specification
====================

This repository contains functional and technical specification documents of the
`Opener Initiative <https://github.com/opener-initiative>`_'s **DECT-2020 NR (DECT NR+)**
protocol stack implementation.

.. note::
   To propose features and requirements to be included in the Opener specification,
   create a pull request and reference `issue #1 <../../issues/1>`_.
